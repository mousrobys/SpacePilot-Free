КОММЕНТАРИЙ ДЛЯ МОДЕРАТОРА
(поле «Напишите любую информацию, которая поможет модератору проверить приложение»)

Просим учесть при проверке:

1. ТИП ПРИЛОЖЕНИЯ
SpacePilot Free — офлайн-анализатор памяти и файловый менеджер.
Приложение показывает занятый объём, находит большие файлы и дубликаты,
управляет файлами в выбранной папке и работает с APK.

2. ИНТЕРНЕТ
Разрешение INTERNET отсутствует. Приложение не выходит в сеть, не содержит
рекламы, аналитики и телеметрии, не требует регистрации и входа.
Проверить: в разделе разрешений приложения нет INTERNET.

3. ОБХОД СИСТЕМНЫХ ОГРАНИЧЕНИЙ
Приложение НЕ запрашивает MANAGE_EXTERNAL_STORAGE и не обходит правила
Android. Доступ к произвольной папке выдаёт сам пользователь через
системный диалог Storage Access Framework: доступ ограничен выбранной
папкой и может быть отозван в любой момент.

4. РАЗРЕШЕНИЯ И ЗАЧЕМ ОНИ НУЖНЫ
READ_MEDIA_IMAGES / READ_MEDIA_VIDEO / READ_MEDIA_AUDIO (Android 13+)
и READ_EXTERNAL_STORAGE (Android 8.0–12L) — чтение медиатеки, чтобы
посчитать занятый объём и найти дубликаты. WRITE_EXTERNAL_STORAGE
(только Android 8.0–9) — удаление медиафайлов через MediaStore на старых
версиях. Никакие другие разрешения не запрашиваются (нет доступа
к контактам, SMS, звонкам, геолокации, камере, микрофону).

5. УДАЛЕНИЕ ФАЙЛОВ
Только после подтверждения пользователем. Для папок SAF используется
системный DocumentsContract.deleteDocument, для медиа на Android 11+ —
системный запрос MediaStore.createDeleteRequest. Скрытого удаления нет.

6. СБОР ДАННЫХ
Приложение не собирает и не передаёт персональные данные. Сведения
о файлах (имя, путь, размер, тип) обрабатываются только на устройстве.
Настройки, история и кэш хранятся в приватном каталоге приложения
и удаляются через «Очистить историю» или при удалении приложения.

7. КАК ПРОВЕРИТЬ ОСНОВНЫЕ ФУНКЦИИ
— Главный экран: нажмите «Сканировать», выдайте разрешения на медиатеку,
  увидите занятый объём и категории.
— «Выбрать папку»: выберите любую папку — откроется файловый менеджер.
— Большие файлы / Дубликаты: фильтры и результаты сканирования.
— APK: список установочных файлов из результатов сканирования.
— Удаление: выберите файл, подтвердите — появится системный диалог.
