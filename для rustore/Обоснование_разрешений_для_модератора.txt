ОБОСНОВАНИЕ РАЗРЕШЕНИЙ ДЛЯ МОДЕРАТОРА
(поле «Чувствительные разрешения — напишите пояснение для модератора»)

ПОЛНЫЙ ВАРИАНТ

SpacePilot Free — офлайн-анализатор памяти и файловый менеджер. Разрешения
используются исключительно для чтения медиатеки на устройстве, чтобы:
— посчитать занятый объём и показать распределение по категориям;
— найти большие файлы и дубликаты (сравнение по размеру и SHA-256).

READ_MEDIA_IMAGES (Android 13+) — чтение изображений для анализа объёма
и поиска дубликатов.
READ_MEDIA_VIDEO (Android 13+) — чтение видео для анализа объёма
и поиска дубликатов.
READ_MEDIA_AUDIO (Android 13+) — чтение аудио для анализа объёма
и поиска дубликатов.
READ_EXTERNAL_STORAGE (только Android 8.0–12L) — то же самое на старых
версиях Android.
WRITE_EXTERNAL_STORAGE (только Android 8.0–9) — изменение и удаление
медиафайлов через MediaStore на старых версиях Android.

Важно:
— разрешение INTERNET отсутствует, приложение не выходит в сеть;
— разрешение MANAGE_EXTERNAL_STORAGE не запрашивается, ограничения Android
  не обходятся;
— доступ к произвольной папке пользователь выдаёт сам через системный
  диалог Storage Access Framework, доступ ограничен выбранной папкой
  и может быть отозван в любой момент;
— удаление файлов выполняется только после подтверждения пользователем,
  для медиа используется системный запрос MediaStore.createDeleteRequest;
— приложение не собирает и не передаёт персональные данные, рекламы
  и аналитики нет.

КОРОТКИЙ ВАРИАНТ (если поле маленькое)

Приложение — анализатор памяти и файловый менеджер. Разрешения нужны,
чтобы считать размеры изображений, видео и аудио, показать занятый объём
и найти дубликаты. Все данные обрабатываются только на устройстве:
разрешение INTERNET отсутствует, данные никуда не передаются и не собираются.

ОДНА СТРОКА

Чтение медиатеки нужно для анализа занятого места и поиска дубликатов;
обработка полностью локальная, INTERNET и MANAGE_EXTERNAL_STORAGE
отсутствуют, данные не передаются.
