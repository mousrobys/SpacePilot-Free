# SpacePilot Free

<p align="center">
  <img src=".github/icon.png" alt="SpacePilot Free" width="160">
</p>

Локальный офлайн-инструмент для анализа памяти Android-устройства: обзор занятого места, поиск больших файлов, поиск дубликатов по содержимому (SHA-256), файловый менеджер через Storage Access Framework, раздел APK и проверка установочных файлов. Интерфейс на Jetpack Compose (Material 3), русский язык по умолчанию, английский — дополнительный. Есть виджет на главный экран со свободным местом и кнопкой «Сканировать».

Приложение не содержит рекламы, аналитики, телеметрии, регистрации и подписок. Все основные операции выполняются на устройстве. Разрешение `INTERNET` объявлено только для необязательной облачной проверки APK по SHA-256 через VirusTotal с вашим собственным API-ключом; по умолчанию функция выключена, и без ключа приложение в сеть не ходит.

## Возможности

- **Обзор хранилища** — общий/занятый/свободный объём, диаграмма, категории файлов, последний скан и история операций.
- **Сканирование** — MediaStore (изображения, видео, аудио) и выбранная пользователем папка через SAF. Прогресс, отмена, отчёт о недоступных путях; результат кэшируется локально.
- **Большие файлы** — вкладки «Все / Видео / Аудио / Изображения / Архивы / APK» со счётчиками. На вкладке «Все» — фильтры 100 МБ / 500 МБ / 1 ГБ, сортировка по размеру, имени, дате; множественное удаление. Остальные вкладки показывают все найденные файлы выбранного типа.
- **Дубликаты** — группировка по размеру, затем SHA-256. Файлы до 32 МБ хэшируются полностью; более крупные — по трём сегментам (начало/середина/конец по 128 КБ) с явной пометкой «выборочная проверка». Выбор лишних копий и удаление.
- **Файловый менеджер** — навигация по выбранной папке, поиск, фильтр по типу, сортировка, информация о файле, открытие, копирование и перемещение; переименование файлов и папок, создание папок, множественный выбор, пакетное переименование по шаблону (`{name}`, `{n}`, `{ext}`) и упаковка выбранных файлов в ZIP в выбранную папку.
- **APK** — список APK из результатов сканирования, сведения о пакете (имя, версия, SDK), запуск системного установщика. Приложение не устанавливает APK в обход системы.
- **Антивирус (эвристический)** — локальная проверка установочных файлов: подпись (SHA-256 сертификата), отладочный сертификат и флаг `debuggable`, опасные разрешения, экспортированные компоненты и простые эвристики с оценкой риска. Необязательно — проверка SHA-256 в VirusTotal по вашему API-ключу; наружу уходит только хеш.
- **Виджет** — свободное место и кнопка «Сканировать» на главном экране (Glance).
- **Безопасное удаление** — подтверждение, для SAF используется `DocumentsContract.deleteDocument`, для MediaStore — системный запрос `MediaStore.createDeleteRequest` на Android 11+; на старых версиях возможен запрос через `RecoverableSecurityException`. Никаких обходов системных ограничений.
- **Интерфейс** — edge-to-edge на Android 15/16; тёмная (по умолчанию), светлая, системная тема; русский/английский/системный язык; управление доступом к папке; очистка истории и сброс; сведения о приложении и политика конфиденциальности.

## Требования

- Android 8.0 (API 26) и выше, targetSdk 36 (Android 16).
- JDK 17, Android SDK Platform 36, Build-Tools 36.0.0.
- Интернет нужен для первой загрузки зависимостей Gradle и, при желании, для облачной проверки APK в VirusTotal (по умолчанию выключена).

## Сборка

Из корня проекта (Windows):

```powershell
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.20.8-hotspot"
.\gradlew.bat :app:assembleDebug --no-daemon
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

JVM-тесты и lint:

```powershell
.\gradlew.bat :app:testReleaseUnitTest :app:lintRelease --no-daemon
```

Если тестовый worker падает с `ClassNotFoundException` из-за кириллицы в пути, создайте junction с ASCII-путём и запустите тесты через него:

```powershell
cmd /c mklink /J C:\spacepilot-build "C:\Users\<user>\Documents\проекты\SpacePilot Free"
cd C:\spacepilot-build
.\gradlew.bat :app:testReleaseUnitTest --no-daemon
```

Подробности: `docs/BUILD_REPORT.md`.

Release-сборка подписывается автоматически параметрами из `keystore.properties` (файл в `.gitignore`). Если файла нет и свойства `-PSPACEPILOT_*` не заданы, на выходе будет `app-release-unsigned.apk`.

Пример с явными свойствами:

```powershell
.\gradlew.bat :app:assembleRelease --no-daemon `
  -PSPACEPILOT_KEYSTORE="keys/spacepilot-release.jks" `
  -PSPACEPILOT_KEYSTORE_PASSWORD="***" `
  -PSPACEPILOT_KEY_ALIAS="spacepilot" `
  -PSPACEPILOT_KEY_PASSWORD="***"
```

Файл `local.properties` уже содержит путь к SDK. Свойство `android.overridePathCheck=true` в `gradle.properties` добавлено из-за кириллицы в пути проекта.

## Установка APK

Соберите APK из исходников (см. раздел «Сборка») — готовый файл появится в `app/build/outputs/apk/`.

```powershell
& "C:\Users\<user>\AppData\Local\Android\Sdk\platform-tools\adb.exe" install -r "app\build\outputs\apk\release\app-release.apk"
```

Или скопируйте APK на устройство и откройте его, разрешив установку из неизвестных источников.

Debug-версия имеет applicationId `com.spacepilot.free.debug` и может стоять рядом с release-версией: `app\build\outputs\apk\debug\app-debug.apk`.

Если система пишет «пакет недействителен»: пересоберите APK и сверьте размер, а также удалите ранее установленную версию с тем же пакетом.

## Ограничения

- Приложение не запрашивает `MANAGE_EXTERNAL_STORAGE`: доступ к файлам ограничен MediaStore и папкой, выбранной через SAF. Полный обход файловой системы недоступен по правилам Android.
- В корзину файлы не помещаются; удаление необратимо после подтверждения (для MediaStore — после системного диалога).
- «Выборочный SHA-256» для файлов >32 МБ теоретически может не отличить файлы с совпадающими размерами и сегментами, но разным содержимым между ними. Это явно показывается в интерфейсе.
- Кэш сканирования ограничен 40 000 файлов; при большем количестве приоритет отдаётся крупным файлам и APK.
- APK-проверка эвристическая: подпись, разрешения, экспортированные компоненты и простые признаки. Она не заменяет полноценный антивирус и не гарантирует обнаружение вредоносного кода. Облачная проверка VirusTotal необязательна, требует собственного API-ключа и отправляет только SHA-256 файла.
- Установка APK выполняется системным установщиком; приложение не устанавливает файлы в обход системы.
- Сборка проверена компиляцией, JVM-тестами, lint и статическим анализом APK. Приложение установлено и просмотрено на эмуляторе Android 14 (1080 × 2340), включая стресс-проверку вёрстки при ширине 360dp и 320dp с масштабом шрифта 1,3. На реальном устройстве запуск не выполнялся. См. `docs/BUILD_REPORT.md`.
- Для установки доступна только v2-подпись (v1 не помещается из-за ограничения ZIP-формата для больших APK). На Android 7+ это штатный вариант; специальные проверки JAR-подписи такие APK отвергают.
