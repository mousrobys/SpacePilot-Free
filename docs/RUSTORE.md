## Полное описание

```
SpacePilot Free — бесплатный офлайн-инструмент для анализа памяти Android-устройства. Приложение помогает понять, чем занято хранилище, найти крупные файлы и дубликаты, навести порядок в выбранной папке и проверить установочные файлы.

Приложение не содержит рекламы, аналитики и регистрации. Все основные операции выполняются на устройстве. Доступ в интернет используется только для необязательной облачной проверки APK по SHA-256 с вашим собственным ключом VirusTotal; по умолчанию она выключена.

ЧТО УМЕЕТ ПРИЛОЖЕНИЕ

• Обзор хранилища: общий, занятый и свободный объём, наглядная диаграмма и распределение файлов по категориям — изображения, видео, аудио, документы, архивы, APK, другое.
• Сканирование: медиатека Android и любая папка, которую вы выберете через системный файловый диалог. Есть прогресс, возможность отмены и отчёт о недоступных местах.
• Большие файлы: вкладки «Все / Видео / Аудио / Изображения / Архивы / APK» со счётчиками; на вкладке «Все» — фильтры от 100 МБ, 500 МБ или 1 ГБ и сортировка по размеру, имени или дате.
• Дубликаты: поиск совпадений по размеру и содержимому (SHA-256). Показываются группы, потенциально освобождаемое место и способ проверки. Файлы крупнее 32 МБ проверяются выборочно по трём сегментам — это честно отмечено в интерфейсе.
• Файловый менеджер: просмотр папок, поиск, фильтры по типу, сортировка, подробные сведения о файле, открытие, копирование и перемещение.
• Порядок в папке: переименование файлов и папок, создание папок, множественный выбор, пакетное переименование по шаблону и упаковка выбранных файлов в ZIP в выбранную папку.
• APK: список установочных файлов из результатов сканирования, имя пакета, версия и SDK, запуск системного установщика.
• Проверка APK: локальный эвристический анализ установочных файлов — подпись и её отпечаток, отладочный сертификат, флаг debuggable, опасные разрешения, экспортированные компоненты и оценка риска. Дополнительно — необязательная проверка SHA-256 в VirusTotal по вашему API-ключу.
• Виджет: свободное место и кнопка «Сканировать» на главном экране.
• Безопасное удаление: только после подтверждения. Для папок используется системный механизм Storage Access Framework, для медиа — системный запрос на удаление Android. Приложение не обходит системные ограничения.
• Настройки: тёмная тема (по умолчанию), светлая или системная; русский, английский или системный язык; очистка истории и кэша, сброс настроек, политика конфиденциальности. Интерфейс учитывает системные отступы Android 15/16 (edge-to-edge).

КОНФИДЕНЦИАЛЬНОСТЬ

Приложение работает на устройстве. Оно не содержит рекламы, аналитики, телеметрии и регистрации, не передаёт имена, пути и содержимое файлов куда-либо. Доступ в интернет используется только для необязательной облачной проверки APK: на сервер VirusTotal отправляется исключительно SHA-256 файла, а не сам файл, и только если вы включили функцию и указали собственный API-ключ. Настройки, история операций и кэш последнего сканирования хранятся только в приватном каталоге приложения и удаляются по кнопке в настройках, при очистке данных приложения или его удалении.

ВАЖНО

• Доступ к файлам ограничен правилами Android: медиатека и папка, которую вы явно выбрали. Приложение не использует MANAGE_EXTERNAL_STORAGE и не читает чужие приватные каталоги.
• Удаление необратимо: корзины нет. Для медиафайлов Android может показать собственный диалог подтверждения.
• Проверка APK эвристическая и не заменяет полноценный антивирус: она не гарантирует обнаружение вредоносного кода. Устанавливайте только файлы из доверенных источников; установку выполняет системный установщик.
• Это анализатор и менеджер файлов, а не «ускоритель» и не средство «очистки всей памяти» в один клик.

Приложение бесплатно, без подписок и встроенных покупок.
```

## Разрешения и пояснения

Список из манифеста:

```
android.permission.READ_EXTERNAL_STORAGE   (maxSdkVersion 32)
android.permission.WRITE_EXTERNAL_STORAGE  (maxSdkVersion 28)
android.permission.READ_MEDIA_IMAGES
android.permission.READ_MEDIA_VIDEO
android.permission.READ_MEDIA_AUDIO
android.permission.INTERNET
```

| Разрешение | Когда | Зачем | Без него |
|---|---|---|---|
| `READ_EXTERNAL_STORAGE` | Android 8–12L, при первом сканировании | Чтение списка изображений, видео и аудио из медиатеки для анализа объёма и поиска дубликатов | Сканирование медиатеки недоступно, остаётся папка через SAF |
| `WRITE_EXTERNAL_STORAGE` | Android 8–9 | Изменение и удаление медиафайлов через MediaStore | Удаление таких файлов может быть недоступно |
| `READ_MEDIA_IMAGES` | Android 13+ | Доступ к изображениям | Изображения не попадут в результаты |
| `READ_MEDIA_VIDEO` | Android 13+ | Доступ к видео | Видео не попадёт в результаты |
| `READ_MEDIA_AUDIO` | Android 13+ | Доступ к аудио | Аудио не попадёт в результаты |
| `INTERNET` | Только при включённой облачной проверке APK | Запрос к VirusTotal по SHA-256 с ключом пользователя | Облачная проверка недоступна, локальная работает |

Ключевое для модерации:

- `INTERNET` используется **только** для необязательной облачной проверки APK по SHA-256; по умолчанию функция выключена, без API-ключа запросы не выполняются.
- `MANAGE_EXTERNAL_STORAGE` — **не запрашивается**.
- Доступ к произвольной папке — не разрешение манифеста, а ручное подтверждение через системный диалог Storage Access Framework; отзывается в настройках.
- Удаление медиа на Android 11+ — через `MediaStore.createDeleteRequest` с системным подтверждением.
- Нет сбора персональных данных, аккаунтов, рекламных и аналитических SDK, телеметрии.

Замечание: библиотека Glance (виджет) подтягивает транзитивные разрешения `WAKE_LOCK`, `ACCESS_NETWORK_STATE`, `RECEIVE_BOOT_COMPLETED`, `FOREGROUND_SERVICE` из `androidx.work`. Собственный код приложения их не использует: фоновых сервисов, автозапуска и сетевой активности, кроме описанной облачной проверки, нет.

## Чек-лист загрузки

1. Загрузить APK `apk/SpacePilot-Free-1.2.0-release.apk`.
2. Вставить название и короткое описание.
3. Вставить полное описание и «Что нового».
4. Выбрать категорию «Инструменты», рейтинг 6+, отметить отсутствие рекламы и покупок.
5. Загрузить иконку `docs/store/icon-512.png`.
6. Добавить скриншоты с устройства.
7. Указать публичный URL политики конфиденциальности.
8. Заполнить контактный e-mail.
9. Перед публикацией заменить ключ разработки `keys/spacepilot-release.jks` на собственный, пересобрать APK и обновить SHA-256 в этом файле.
