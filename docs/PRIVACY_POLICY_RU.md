# Политика конфиденциальности SpacePilot Free

**Дата вступления в силу:** 23 октября 2026 года
**Версия приложения:** 1.0.0
**Разработчик:** _указать имя/организацию_
**Контакт:** _указать e-mail_

Настоящая политика описывает, как приложение SpacePilot Free (далее — «приложение», пакет `com.spacepilot.free`) обращается с данными на устройстве пользователя.

## Кратко

- Приложение работает полностью офлайн и **не имеет разрешения на доступ в интернет**.
- Приложение не собирает, не передаёт и не продаёт персональные данные.
- Нет аккаунтов, рекламы, аналитики, телеметрии, сторонних рекламных или трекинговых SDK.
- Все настройки, история и кэш сканирования хранятся только на устройстве, в приватном каталоге приложения.
- Пользователь сам выбирает папку для доступа и подтверждает удаление файлов.

## 1. Какие данные обрабатываются

Приложение получает доступ к сведениям о файлах только в объёме, необходимом для его функций:

- имя файла, размер, дата изменения, MIME-тип, путь или URI;
- содержимое файла — только для вычисления контрольной суммы SHA-256 при поиске дубликатов или по запросу «Рассчитать SHA-256»;
- сведения об APK — имя пакета, версия, минимальная и целевая версия SDK, название приложения;
- объём хранилища устройства (общий, занятый, свободный);
- выбранная пользователем папка (URI доступа Storage Access Framework).

Эти сведения обрабатываются локально и не отправляются за пределы устройства.

## 2. Разрешения и доступ

Приложение запрашивает:

- `READ_EXTERNAL_STORAGE` — только на Android 8–12L, для чтения медиатеки (изображения, видео, аудио).
- `WRITE_EXTERNAL_STORAGE` — только на Android 8–9, для операций с медиафайлами.
- `READ_MEDIA_IMAGES`, `READ_MEDIA_VIDEO`, `READ_MEDIA_AUDIO` — на Android 13 и выше, для доступа к соответствующим коллекциям медиатеки.

Приложение **не запрашивает** `INTERNET`, `MANAGE_EXTERNAL_STORAGE`, доступ к контактам, SMS, геолокации, камере или микрофону.

Доступ к произвольной папке предоставляется пользователем вручную через системный диалог Storage Access Framework. Приложение получает доступ только к выбранной папке и её содержимому. Пользователь может отозвать доступ в настройках приложения или в системных настройках Android.

## 3. Как используются данные

Данные используются исключительно для:

- отображения занятого места и категорий файлов;
- поиска больших файлов и дубликатов;
- навигации по выбранной папке, поиска, копирования и перемещения файлов;
- отображения сведений о файлах и APK;
- удаления файлов после явного подтверждения пользователем;
- сохранения настроек интерфейса и последнего результата сканирования.

Приложение не использует данные для рекламы, профилирования, аналитики или автоматизированного принятия решений.

## 4. Локальное хранение

На устройстве сохраняются:

- настройки: тема, язык, URI выбранной папки — в приватных `SharedPreferences` приложения;
- журнал последних операций (до 25 записей: тип, время, описание, объём) — в приватных `SharedPreferences`;
- кэш последнего сканирования (имена, пути/URI, размеры, даты, категории, до 40 000 записей) — в сжатом JSON-файле в приватном каталоге приложения;
- временная копия APK для чтения метаданных — в кэше приложения, удаляется после анализа.

Эти данные не покидают устройство. Журнал операций и кэш сканирования удаляются кнопкой «Очистить историю и кэш»; настройки темы и языка сбрасываются отдельной кнопкой. Все локальные данные также удаляются при очистке данных приложения в настройках Android или при удалении приложения.

## 5. Передача третьим лицам

Приложение не передаёт данные третьим лицам. В нём нет серверной части, облачной синхронизации, рекламных сетей и сторонних SDK, собирающих данные.

Если пользователь открывает файл или запускает установку APK, управление передаётся другому приложению через системный механизм Android (Intent). Это приложение может иметь собственную политику конфиденциальности; SpacePilot Free не контролирует его действия.

## 6. Удаление файлов

Удаление выполняется только после подтверждения пользователя. Для папок, выбранных через Storage Access Framework, используется системный API удаления документов. Для медиатеки на Android 11 и выше показывается системный диалог подтверждения удаления. Приложение не обходит системные ограничения и не удаляет файлы скрытно.

Удалённые файлы не помещаются в корзину и не могут быть восстановлены средствами приложения.

## 7. Безопасность

Приложение минимизирует объём обрабатываемых данных и не имеет сетевого доступа. Доступ к файлам ограничен разрешениями Android и выбранной пользователем папкой. Тем не менее ни одно устройство и ни одно программное обеспечение не гарантируют абсолютной безопасности; пользователь устанавливает приложение и работает с файлами на свой риск.

## 8. Дети

Приложение не предназначено для сбора данных о детях и не собирает персональные данные пользователей любого возраста. Возрастной рейтинг — 6+.

## 9. Изменения политики

Политика может обновляться при изменении функций приложения. Актуальная версия всегда публикуется по адресу, указанному в карточке приложения. Дата вступления в силу указана в начале документа.
